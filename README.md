# Denoising Autoencoder

A compact TensorFlow starter for image denoising with a convolutional autoencoder. It is structured for experimentation with small RGB image datasets.

## Run

```bash
pip install -r requirements.txt
python3 train.py
```

The script uses CIFAR-10 when TensorFlow is available and trains a small model for a short demo run.

## Stack

Python · TensorFlow · Keras · CNN autoencoder
